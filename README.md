I build public-data and financial-risk software. The work usually begins with filings, official datasets, or live market feeds and ends as a terminal, API, MCP server, or verifiable record.

## Open-source tools

[Noisefloor](https://github.com/beepboop2025/noisefloor) handles peek-safe experiments, change detection, and forecasts. [PDF Suite MCP](https://github.com/beepboop2025/pdf-suite-mcp) exposes 37 local PDF operations. [Lucent](https://github.com/beepboop2025/lucent) checks ERC-7730 clear-signing descriptors before a transaction is signed. [EconScraper](https://github.com/beepboop2025/econscraper) monitors economic-data sources for outages, stale updates, and structural drift.

## Working principles

Methods, sources, data timestamps, and known limits belong next to the output. Backtests include misses. Live surfaces show missing or stale data instead of quietly reusing an old value.

Most of the stack is Python or TypeScript, with FastAPI, Next.js, Postgres, and small dependency-light tools where a framework would add more than it solves.
